# Security

Iconbloom changes files and settings on your PC, asks for administrator permission for
shortcuts every user shares, and installs its own updates, so security reports matter.

## Supported versions

Only the latest release. The app offers updates when it opens.

## Reporting a problem

Please report privately through GitHub: the repository's **Security** tab, then
**Report a vulnerability**. Don't open a public issue. You'll get an answer within a week.

Things worth a report include a way to make Iconbloom change something other than an icon,
to make its administrator helper act on files outside the shared shortcut folders, or to make
it install an update that doesn't match its published checksum.
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) describes how each of those is guarded.
